TUULI DESIGN – 1A-ULKOASU / DESIGN (EN + DE, SVG)
=====================================================

LÄHTÖKOHTA
Tämä paketti perustuu nimenomaan Tuuli Designin alkuperäiseen
1A-versioon (Tuuli_Design_GitHub_JPG_toimiva.zip), ei 1B/1C-versioihin.
1A:n tekstilogo, fontit, värit, asettelu, sisällön rakenne ja taulukko
on säilytetty. Ainoa ulkoasulisäys on EN / DE -kielivalinta.

SIVUT
 index.html          englanninkielinen Home
 services.html       englanninkielinen Services
 portfolio.html      englanninkielinen Portfolio
 de/index.html       saksankielinen Startseite
 de/services.html    saksankielinen Leistungen
 de/portfolio.html   saksankielinen Portfolio
 style.css           yksi yhteinen CSS-tiedosto
 *.svg               neljä sisustus- ja henkilökuvitusta vektorimuodossa

KIELENVAIHTO
Jokaisen sivun yläosassa on EN / DE -linkit. Kieltä vaihdettaessa
sivun aihe säilyy (Home ↔ Startseite jne.). Kieli on toteutettu
HTML-linkeillä ilman JavaScriptiä, evästeitä tai ulkoisia palveluja.

SVG-KUVAT
Kaikki 1A:n alkuperäiset JPG-kuvitukset on korvattu alkuperäistä
1A-ulkoasua mukailevilla SVG-vektoripiirroksilla. SVG-tiedostoissa
ei ole upotettuja JPG/PNG-rasterikuvia. Kuviot ovat muokattavissa
vektorikuvankäsittelyohjelmilla. Ne eivät ole pikselintarkkoja
kopioita JPG-versioista.

JULKAISU GITHUB PAGESIIN
1. Luo uusi repository (esim. tuuli-design-1a-en-de).
2. Pura ZIP ja lataa SEN SISÄLTÖ repositoryn juureen.
   index.html ja style.css kuuluvat repojuureen; de-kansio säilyy.
3. Settings → Pages → Deploy from a branch → main → /(root).
4. Avaa GitHub Pages -osoite. Kokeile EN/DE-valintaa ja navigointia.

HUOMAUTUS
Sivusto on opiskeluprojekti, ei toimiva varauspalvelu.
Tiinan kuva on kuvitus / paikkamerkki, ei valokuva.
