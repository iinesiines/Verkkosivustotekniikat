TUULI DESIGN – STUDENT WEBSITE (HTML + CSS only)

FILES
index.html        Home
services.html     Services + ordered list
portfolio.html    Portfolio + table
style.css         One shared CSS file
images/           Original SVG illustrations (no external downloads)

OPEN LOCALLY
Open index.html in a browser, or use Visual Studio Code Live Server.
No JavaScript or build tools are needed.

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository called tuuli-design (or another name).
2. Upload index.html, services.html, portfolio.html, style.css and images/ directly into the repository root.
3. Open Settings > Pages > Build and deployment. Set Source: Deploy from a branch.
4. Select branch main and folder /(root), then Save.
5. Open the published URL shown by GitHub. Example: https://USERNAME.github.io/tuuli-design/
6. Check every page and run WAVE on the public URLs.
